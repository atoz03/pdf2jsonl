    全部论文

    相同 PDF 自动归为同一篇论文。
    站点页面收录仓库内 examples/ 与 papers/ 下的论文和运行；本地运行目录用 make dashboard 查看。

    添加论文与更新看板

    PDF、运行结果和论文历史会在生成看板时自动汇总。

    1

    将 PDF 放入仓库

    建议放在 papers/。尚未抽取的文献也会出现在论文列表中。

    2

    运行抽取流程

    使用 pdf2jsonl 处理论文，将结果保存在仓库内。默认 agent 模式需要模型填写候选，再执行 finalize。

    skills/pdf2jsonl/scripts/pdf2jsonl papers/paper.pdf --out-dir out/paper --bundle
    3

    重新生成，然后刷新页面

    make dashboard

    看板展示生成时的数据快照，不会自行启动模型或修改论文数据。

    要让论文出现在发布站点的论文页，把 PDF 和运行结果放在 papers/ 或 examples/ 下并提交；make site 与 Pages 工作流只收录这两个目录。
