# 生物育种 JSONL 精简字段版

## 文件定位

本文件从完整 259 字段中筛选出 **157 个首批生产字段**，用于 PDF 到 JSONL 的小批量试跑、课题二和课题三的最小闭环，以及首版图谱/语料/问答派生。字段路径沿用 v3，不改变既有字段语义，因此可以无损回填到完整字段目录。

精简版优先保留四类信息：

- 文献和数据来源：稳定 ID、DOI/URI、页码、章节、表图、原文证据和审核状态。
- 育种事实：作物、群体、材料、环境、性状、基因、变异、QTL、测量和实验条件。
- 智能体与技能：科学问题、发现、证据链、实验设计、方法、参数、验证和工作流。
- AI 派生：图谱主谓宾、关系限定、Chunk、QA 支持证据、推理难度、训练划分和许可。

## 使用边界

- 精简版适合首批 PDF 抽取和数据质量调试，不取代完整 259 字段目录。
- 论文没有报告的字段继续省略，不使用空字符串、`null` 或猜测值。
- 复杂资产、稀疏基因型、许可证、冲突消解和长期版本管理仍应使用完整字段版。
- 通过 `record_id + source_id + source_locator` 保持与完整字段版的回填关系。
- 当项目接入基因组数据库、图结构数据库或课题三工具 Markdown 后，再按完整字段目录增量补充。

完整字段说明见 [breeding_fields_259_intro.md](breeding_fields_259_intro.md)。
